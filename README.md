# Flee The Facility
 A game for Hack Club Terra.

Controls:
Move up - W/arrow up
Move down - S/arrow down
Move left - A/arrow left
Move right - D/arrow right
Jump - spacebar

Special Features of the game: Tilemap-based movement, minimap, lighting/shadows, item trackers, distance trackers, original ost, original art.

Story - You are a slime trying to escape a facility! Escape past the confusing maze and the daunting platformer in order to flee the facility!

Additional Info:
It is comprised of a tilemap layer movement mechanic maze and a platformer. The audio there is the first music or ost I have ever made (it sucks, but at least #noaislop) and all art are mine. Some features include: minimaps, distance trackers, items, lighting,. and the tilemap movement. I hope everyone would have fun (or be unsettled LOL) of the game that represents everything I know so far. 

Context: I have long wanted to make my own osts in games so this game is an opportunity for me to do so with my new Korg Nanokey 2 I got from Hack Club Jame Gam. Furthermore, this game represents everything I have learned in my 1 year game dev journey so far. This also served as a refresher because it has been months since I last used Godot. Anyways I am proud and I hope everyone enjoys.

Tools/Apps: Aseprite, Godot, Korg Nanokey2.
